## 2026-07-25 - Caching Static Assets in Express Backend
**Learning:** In a typical Express + Vite setup where the backend serves static frontend files, return visitors download identical bundled assets unnecessarily. The out-of-the-box `express.static` lacks aggressive caching rules. By differentiating between the mutable `index.html` (which should never be cached) and hashed assets in `/assets/` (which can be cached indefinitely), load times and backend load can be optimized significantly.
**Action:** Use the `setHeaders` configuration in `express.static` to dynamically apply `Cache-Control: no-cache` for `.html` files and `Cache-Control: public, max-age=31536000, immutable` for files in the `/assets/` directory.
